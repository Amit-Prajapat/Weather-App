# Weather App

A simple and responsive weather application that allows users to search for a city and view its current weather information. The application is built using **HTML, CSS, and JavaScript** and uses the **OpenWeather API** to fetch real-time weather data.

## Set Up / Get Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Weather-App.git
   ```

2. Open the project folder:

   ```bash
   cd Weather-App
   ```

3. Open `index.html` in your browser.

You can also access the live website here:
**[Live Demo](http://127.0.0.1:5500/index.html)**

## Features

* Search for the weather of any city
* Display current temperature
* Display humidity and wind speed
* Show weather conditions and corresponding weather icons
* Display an error message for invalid city names
* Responsive design for different screen sizes

* HTML
* CSS
* JavaScript
* OpenWeather API
